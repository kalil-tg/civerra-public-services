# Manual QA Plan

Before any broad conformance claim:

- Complete keyboard traversal, reverse traversal, focus visibility at 200%/400%, and file-control checks
- Test NVDA with current Chrome and Firefox on Windows
- Test VoiceOver with Safari on macOS/iOS when available
- Verify error-summary announcements, step context, native controls, upload state, save status, and confirmation
- Test forced colors, text-spacing overrides, reflow at 320px, and zoom at 400%
- Record browser/AT versions, scenario, result, severity, reproduction steps, and retest evidence

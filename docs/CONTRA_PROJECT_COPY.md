# Contra Project Copy

## Title

CIVERRA — Accessible Public-Services Application Flow

## Short description

A complex React application journey rebuilt with focused errors, semantic form controls, resilient mobile reflow, and regression tests.

## Overview

CIVERRA is a self-initiated technical case study for a fictional European public-services portal. I designed and built the dashboard and a five-step housing-support flow, then treated accessibility as part of the interaction architecture.

The experience includes explicit progress, deadlines, documents, official messages, grouped native controls, a focused error summary, linked field errors, file upload, save feedback, responsive application details, and a review confirmation.

## Deliverables demonstrated

- React and TypeScript implementation
- Complex multi-step form UX
- Keyboard and focus management
- Accessible validation and native controls
- Responsive 390px reflow with no horizontal overflow
- Playwright and axe-core regression coverage
- Controlled before-state fixture and documented evidence boundaries

Five end-to-end scenarios pass. This does not claim certification, legal compliance, or completed screen-reader validation.

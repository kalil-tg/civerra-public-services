# CIVERRA Design System

- Direction: European public-service editorial clarity
- Display: Libre Baskerville
- Interface: Public Sans
- Surfaces: true white and pale blue-gray
- Primary: saturated cobalt
- Text: very dark navy
- Attention: dark red with icon and written message
- Geometry: 4–6px corners, thin rules, almost no shadow
- Containers: open lists, bands, rails, and one purposeful application frame

Interaction rules: native controls first; selection is explicit in text and state; focus is highly visible; form errors appear both in a summary and beside the affected field; motion respects `prefers-reduced-motion`.
